# Inkstep release baseline

This branch contains release validation configuration, with no application implementation yet.
The initial application is reviewed on `feat/inkstep-tutor` before it enters `main`.
The repository is private while the submission is being prepared.
CI verifies unit behavior, browser interactions in the exported notebook, lint, type checking, and the production build.
Real DeepSpace integration and physical iPad checks are reported separately with their actual evidence and limitations.
